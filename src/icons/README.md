# Local Lucide icons

The unchanged `footprints.svg`, `tree-pine.svg`, `circle-check.svg`, `circle.svg`
and `circle-minus.svg`, plus the planner's `route.svg`, `map-pin.svg`, `x.svg`
and `chevron-down.svg` assets come from the upstream Lucide icon directory:
https://github.com/lucide-icons/lucide/tree/main/icons
on 13 November 2026. The accompanying upstream license is in
`LUCIDE-LICENSE.txt` (ISC; the notice also lists Feather-derived icons).

The application uses these small local SVGs as CSS masks, inheriting text colour.
No icon library, external runtime request or JavaScript dependency is needed.
